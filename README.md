# UiPath-UnicornName

# 🦄 Unicorn Name Automation

An automation project built with **UiPath Studio Web** to process a spreadsheet containing names and birth months, then generate or retrieve corresponding unicorn names.

## 📌 Project Overview

Unicorn Name is a beginner-level Robotic Process Automation (RPA) project designed to automate spreadsheet processing and email delivery.

The project works with a workbook containing personal names, birthday months, and a column for unicorn names. The automation is intended to process the data and deliver the completed workbook via email.

## 🎯 Objectives

- Practice building automation workflows using UiPath Studio Web.
- Automate spreadsheet data processing.
- Learn browser and application automation.
- Understand email automation and file attachments.
- Develop basic RPA workflow skills.

## ⚙️ Workflow

1. **Initialize Workflow** – Start the automation process.
2. **Process Spreadsheet** – Access and process the provided workbook.
3. **Generate Unicorn Names** – Process the data to obtain corresponding unicorn names.
4. **Update Spreadsheet** – Store the results in the Unicorn Name column.
5. **Send Email** – Send the workbook as an email attachment.
